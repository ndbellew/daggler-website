## Summary

This document examines layered network defense and firewall selection for small businesses operating with limited budgets, staffing, and security expertise. It describes defense-in-depth as the use of multiple controls supported by risk assessment, network boundaries, access management, monitoring, and ongoing review.

The discussion compares stateful inspection, proxy, web application, unified threat management, and next-generation firewalls. It recommends a next-generation firewall as a primary network firewall because it can consolidate application control, intrusion prevention, threat detection, and management capabilities. It also acknowledges cost and misconfiguration risks and argues that a firewall should be supplemented by endpoint firewalls, software updates, authentication controls, backups, and network segmentation.
